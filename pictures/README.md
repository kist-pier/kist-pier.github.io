# Raw image archive

`pictures/` stores original images. The deployed website uses optimized copies
from `assets/img/`.

Naming rules:

- Directory names: lowercase kebab-case, such as `lab-equipment` and `lab-life`.
- Image names: lowercase snake_case.
- Dated events: `YYYY-MM-DD_description_01.jpg`.
- Member portraits: `givenname_familyname.jpg`, matching `assets/img/members/`.
- JPEG images always use `.jpg`; PNG images use `.png`.
- Avoid spaces, uppercase letters, Korean characters, commas, and other punctuation.

Examples:

- `members/wonseok_choi.jpg`
- `conferences/2026-02-05_kroc_01.jpg`
- `lab-life/2026-01-09_kist_air_lab_dinner.jpg`
