# Publication preview assets

Use lowercase kebab-case filenames:

- Conferences: `<venue>-<year>.svg`
- Journals and societies: `<venue>.svg`

Each SVG is a local wrapper around the venue's official raster artwork. This
keeps the public page stable when an archive site changes or removes an image.

| File | Official source |
| --- | --- |
| `corl-2026.svg` | [CoRL 2026](https://2026.corl.org/) |
| `icra-2024.svg` | [ICRA 2024 logo downloads](https://2024.ieee-icra.org/contribute/) |
| `icarm-2019.svg` | [ICARM 2019](https://www.ieee-arm.org/icarm2019/) |
| `iros-2025.svg` | [IEEE RAS IROS venue archive](https://www.ieee-ras.org/conferences-workshops/financially-co-sponsored/iros/iros-past-and-future-venues/) |
| `tmech.svg` | [IEEE/ASME Transactions on Mechatronics](https://www.ieee-asme-mechatronics.info/) |
| `jkros.svg` | [The Journal of Korea Robotics Society](https://journal.kros.org/) |
| `kros.svg` | [Korea Robotics Society](https://kros.org/) |

RA-L is intentionally rendered with the text fallback. Its official page does
not publish a distinct journal logo, so a generic IEEE RAS logo would be
misleading.
